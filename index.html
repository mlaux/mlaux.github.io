Recent projects

Here are some of the programming projects I've been working on. Most of these are focused on retrocomputing (and a lot of retro gaming recently, for some reason), but not because of nostalgia (I wasn't around when most of this stuff was current) - programming for old systems is just fun because it's actually possible for one person to mostly understand everything that's going on, from the CPU up.

This is in contrast to how I develop professionally, where I use the modern tools and processes necessary to produce a high-quality, maintainable product, no matter how many layers of abstraction are involved. :-)

Gray Brick (formerly gb6)

This is a Game Boy emulator for System 6 featuring a JIT compiler to achieve playable speeds on an average 68030 based Mac. My target machine was the Macintosh IIci, which came out the same year as the Game Boy and features the ~amazing~ 25 MHz 68030. Downloads and more info available here.

Crane SNES graphics editor

Web-based editor for 4bpp SNES graphics. Supports creation of 8x8 and 16x16 tiles and placing the tiles in backgrounds. Also supports assignment of colors to palettes. Crane is under active development and feature requests are welcome - I wrote this for my own game but it might be useful to y'all too!

SNES/SFC EPROM Cartridge

Modifying the SHVC-1A0N-01 SNES cartridge PCB to accept a 27C040 EPROM.

TECHNO Style Essentials

TECHNO Style Essentials is a IIDX tier list... this time for Android and iOS!

Erik Satie's Vexations (MS-DOS version)

An art project for the IBM PC and Yamaha YM3812 (AdLib). Vexations is a piano piece that the composer ostensibly wished to be played 840 times in a row. My version flips a random bit in the synthesizer patch each iteration to gradually distort the sound.

IIDX Tier List

This application allows you to track your scores on level 11 and 12 notecharts in beatmania IIDX. Screenshots are from the Mini vMac emulator, but this has also been successfully tested on a real Macintosh Plus!
